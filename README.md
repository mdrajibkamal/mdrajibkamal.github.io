# Md Rajib Kamal — Academic Website

A simple, responsive academic website designed for GitHub Pages.

## Included files

- `index.html` — home page
- `research.html` — publications, thesis papers, working papers, research in progress
- `teaching.html` — teaching and supervision
- `other.html` — education, appointments, awards, methods, languages
- `assets/profile.jpg` — profile photo
- `assets/Rajib_Kamal_CV.pdf` — CV
- `css/style.css` — site design
- `js/site.js` — mobile menu and copyright year

## Publish with GitHub Pages

1. Sign in to GitHub and create a new public repository named `YOURUSERNAME.github.io`.
2. Upload all files and folders from this package to the repository root.
3. Open the repository's **Settings → Pages**.
4. Under **Build and deployment**, choose **Deploy from a branch**.
5. Select the `main` branch and `/ (root)`, then save.
6. After GitHub finishes deployment, the site will appear at `https://YOURUSERNAME.github.io/`.

## Important optional edits

The CV listed profile services such as Google Scholar, SSRN, LinkedIn, and a personal website, but the PDF text available here did not expose their actual URLs. They were therefore not guessed or hard-coded. Once you have the exact links, add them to the `quick-links` section in each HTML page.

You can edit the site in any text editor, including VS Code.
